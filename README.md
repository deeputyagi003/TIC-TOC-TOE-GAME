# 🕹️ Tic-Tac-Toe Game

A clean, modern, and fully responsive implementation of the classic **Tic-Tac-Toe** (X and O) game built for the web.

## 🚀 Features
* **Responsive Design:** Fully optimized to be playable across all devices, including mobile, tablets, and desktops.
* **Interactive UI:** Smooth transitions, hover effects, and modern styling.
* **Win/Draw Detection:** Real-time logic checks for wins (horizontal, vertical, diagonal) and tie games instantly.
* **Score Tracker / Restart:** Easily reset the game board to keep playing multiple rounds.
* *(Optional)* **AI Opponent:** Single-player mode featuring a smart computer opponent (e.g., using the Minimax algorithm).

## 🛠️ Technologies Used
* **HTML5:** For semantic web structure and layout.
* **CSS3:** For modern custom styling and grid system layouts.
* **JavaScript (ES6):** For game engine architecture, event handling, and winning logic.

## 🎮 How to Play
1. The game is played on a grid that's 3 squares by 3 squares.
2. Player 1 is **X** and Player 2 (or the computer) is **O**. Players take turns putting their marks in empty squares.
3. The first player to get 3 of their marks in a row (up, down, across, or diagonally) is the winner.
4. When all 9 squares are full, the game is over. If no player has 3 marks in a row, the game ends in a tie.

## 💻 Local Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Launch the game:**
   Simply open the `index.html` file directly in any modern web browser.
